# SACOR Adoption Metrics

This document tracks public adoption over time. The goal is to
measure trends, not individual events — two days of data mean
nothing, four weeks starts to. Snapshot every Sunday. Traffic numbers
are GitHub's rolling 14-day window (`Insights → Traffic`) — record
them before they roll off. Stars/forks/external issues/discussions/
PRs are cumulative counts, not weekly deltas.

## Success Criteria

The project is considered to be gaining adoption when at least one of
the following occurs:

- First external GitHub Issue
- First external Discussion
- First external Pull Request
- First external Fork
- First external user reporting successful production use

Stars are tracked but are not considered the primary adoption metric.
