# examples

`sample.pdf` — synthetic electricity bill (`corpus/synth/S001.pdf`), no
real data, generated by `scripts/genera_corpus.py`. Used by the README
Quick Start so `sacor extract` has something to run on immediately.

`sample-output.json` — `sacor extract sample.pdf` output on this exact
file, tier0 only (no `--tier1`, no API key). Regenerate after a schema
or output-shape change:

```bash
sacor extract examples/sample.pdf > examples/sample-output.json
```
