# Adoption metrics

Weekly snapshot, every Sunday. Traffic numbers are GitHub's rolling
14-day window (`Insights → Traffic`) — record them before they roll
off. Real adoption signals (stars/forks/external issues, PRs,
discussions) are cumulative counts, not weekly deltas.

Not a vanity-metric log — the point is trend over weeks, not any
single number. Two days of data means nothing; four weeks starts to.

## What actually matters

First real signal from a stranger, whichever comes first:

- [ ] First star from someone not the maintainer
- [ ] First issue opened by an external user
- [ ] First discussion opened by an external user
- [ ] First fork
- [ ] First external PR
- [ ] First "I installed sacor and..." mention anywhere public
